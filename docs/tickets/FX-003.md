# FX-003 — Motion blur (reprojecting the last frame's view)

- **Status:** DONE (2026-10-21)
- **Priority:** P3
- **Module:** Post-FX
- **Depends on:** FX-000
- **Files:** `src/Render/PostProcess.{h,cpp}`, `assets/shaders/postprocess.frag`

## Done
- `PostProcess::EndScene` takes the frame's view-projection and keeps it for the next frame.
- The last pass reads the scene's depth (its frame buffer's depth texture), takes each pixel
  back into the world with this frame's inverse view-projection and onto the screen with
  the last frame's: where the pixel was a frame ago. The scene is sampled eight times along
  that, the motion's length kept to 5 % of the screen (no smear across a cut or a quick
  turn).
- Off by default; its strength in the Post-FX window. Only the camera's motion: the cars'
  own is not measured.

## Acceptance criteria
- [x] The last view-projection kept, the inverse of this one passed.
- [x] The scene's depth read as a texture to rebuild the world position.
- [x] Sampled along the screen motion, its length clamped.
