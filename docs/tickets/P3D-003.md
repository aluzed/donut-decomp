# P3D-003 — Facial expression chunks

- **Status:** DONE (2026-10-21)

## Context
The facial expression chunks (morph targets) were in `ChunkType` but described nowhere:
`Expression` (0x21000), `ExpressionGroup` (0x21001), `ExpressionMixer` (0x21002);
`ExpressionOffsets` (0x10018) and `OffsetList` (0x1000E) were in `p3d.unused.json` with a
layout that did not fit.

## What the data says
Only the living room's `camset_C.p3d` and `camset_H.p3d` hold any: two eyes' meshes, each
with one expression ("close": a blink) of 118 and 66 vertex offsets.

| Chunk | Layout |
|---|---|
| `ExpressionGroup` | version, name, target (the mesh), stage count, stages (u32); its `Expression`s as children |
| `Expression` | version, name, key count, keys (float), indices (u32) |
| `ExpressionMixer` | version, name, type (3), target, the group's name |
| `ExpressionOffsets` (under a `PolySkin`) | version, primitive group count, their indices; its `OffsetList`s as children |
| `OffsetList` | count, primitive group, then per offset its vertex's index (u32) and the offset (vec3); a last u32, 0 in both files |

Every one of them reads to its last byte with this layout (the last `OffsetList` word
aside, whose meaning the two files cannot tell: both hold 0).

## Done
- The five described in `p3d.json` and generated. `OffsetList`'s offsets are each an index
  and a vector in turn, which the generator cannot say: read by hand, in
  `hand-edits.patch`, as `MultiControllerTracks`' tracks are.
- `GameExpressions` (`tests/`) reads the camset files' through the generated classes: each
  mixer's group is there, the keys and indices as many as they say, the offsets' vertices in
  order.
- Not drawn: the living room's eyes do not blink. Its scene is drawn without the morphs.
